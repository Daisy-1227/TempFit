TempFit installation

Requirements

Linux or WSL (x86_64, glibc 2.28+), Python 3.10, and an NVIDIA GPU with BF16 support.
Allow 15 GB of disk space. Dependencies use CUDA 11.8; the installer supplies the runtime libraries.

Clone the repository

  git clone https://github.com/Daisy-1227/TempFit.git
  cd TempFit

Install with Conda (Anaconda, Miniconda, or Miniforge)

  conda create -n tempfit python=3.10 pip -y
  conda activate tempfit
  export CUDA_VISIBLE_DEVICES=0
  bash environment/install.sh --conda

Conda provides Python and pip; the installer installs the project dependencies into the active environment.
Set CUDA_VISIBLE_DEVICES to the GPU you want to use.

Install with venv

  export CUDA_VISIBLE_DEVICES=0
  PYTHON=python3.10 bash environment/install.sh "$HOME/venvs/tempfit"
  source "$HOME/venvs/tempfit/bin/activate"

Use a new directory for the venv. PYTHON can also be an absolute path to a Python 3.10 executable.

Check the installation

  python -m pip check
  python -c 'import json, sys; from pathlib import Path; print(json.loads((Path(sys.prefix) / "ENVIRONMENT_CHECK.json").read_text())["passed"])'

The installer applies the x-transformers patch and runs dependency, BF16, CUDA kernel, and attention-gradient checks.
A successful installation produces ENVIRONMENT_CHECK.json with "passed": true.

Downloads and offline installation

The first installation downloads 89 wheels totaling 3.23 GB. Verified files are cached in:

  ${XDG_CACHE_HOME:-$HOME/.cache}/tempfit/env-cu118-py310-v1

To download once and install from a local wheelhouse:

  python environment/download.py --destination /path/to/wheelhouse
  bash environment/install.sh --conda /path/to/wheelhouse

For venv, replace --conda with the new environment directory.
The downloader checks SHA256 hashes, reuses verified files, and retries failed downloads.

Dependencies

PyTorch 2.5.0+cu118, torchvision 0.20.0+cu118, and x-transformers 2.3.12 with the project patch are pinned.
FlashAttention 2.7.4.post1+p1industry supports the project's forward/backward paths with dropout=0,
without ALiBi, softcap, or local-window attention. Package versions and hashes are in requirements.txt and DOWNLOAD_MANIFEST.json.

Dependency wheels: https://github.com/Daisy-1227/TempFit/releases/tag/env-cu118-py310-v1
The standalone v1 installer archive uses venv; use the current repository scripts for Conda support.
Third-party license notices are in environment/licenses/. Validation records are in environment/VALIDATION.json.
